# Vault Exporter (`true-condensated-vault-exporter`)

Plugin Obsidian modulaire et personnalisable pour exporter un coffre (ou un dossier) vers plusieurs formats :
- **Texte consolidé pour NotebookLM** : format nettoyé, optimisé pour les carnets de sources et requêtes IA.
- **HTML consolidé** : vue document stylisée et lisible.
- **Markdown consolidé** : document unique unifié.
- **Split export** : export structuré par dossiers et thématiques.

Moteur 100 % TypeScript, export asynchrone non bloquant avec bouton d'annulation.

## Commandes de développement

```bash
npm install
npm run dev
npm run check
```
