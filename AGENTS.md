# Contributor entry point

Before making changes, read `NEXT_SESSION.md` for the current state, then `CONTEXT.md` for architecture and project invariants.

Keep code and user-facing text in English. Run `npm run check` before considering a code change complete. Preserve the Arena session branch; do not switch branches.

## Toute IA (Hermes, Codex, Gemini, Antigravity)

Les lignes `@...` ci-dessus ne sont interprétées que par Claude Code : les autres outils n'en lisent pas le contenu.
Tout outil lit donc lui-même les fichiers cités, dans l'ordre indiqué, avant d'agir : `NEXT_SESSION.md`
(état présent), puis `context.md`/`CONTEXT.md` (règles, architecture, commande de vérification).
Règles communes à tous les projets du coffre : `../METHODE.md` (le projet prime s'il justifie l'écart).
